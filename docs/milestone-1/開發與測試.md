更新日期：2026-10-03。主方案A版（Cloudflare），替代方案B2保留。
狀態：可本機測試；未部署，尚不可直接作為正式活動系統。

## 已完成
- TypeScript/Vite/Workers正式骨架；Prototype dist/index.html保留不動。
- 後台登入、選用發布題庫建立房間、QR Code加入、真實在線名單、瀏覽器身分恢復。
- 主持人開始、提前收題、公布正解、下一題、跨回合、提前結束、關閉房間。
- D1正式題庫：新增／編輯／儲存草稿、題目排序與刪除、正解／秒數／配分、發布、封存。
- 草稿可留白儲存，未設定答案以-1表示；發布時完整驗證1～60題與三回合。
- 草稿與發布內容分開；房間固定題庫快照，後續修改、再發布或封存不影響既有房間。
- 版本條件更新避免舊分頁覆蓋；發布及封存也會推進版本。
- 管理員工作階段用HttpOnly／SameSite=Strict cookie，公開HTTPS加Secure；一小時到期，登出撤銷、更換管理密碼也使舊登入失效。
- 本機仍保留三回合示範題；公開環境API要求選用已發布題庫，不接受示範題或自訂題目。
- 以伺服器截止時間收答案、持久儲存、冪等提交、固定配分、同分並列。
- 正解、個人本題得分及新增分數在公布前不傳給玩家。
- Hibernation WebSocket、房間重建恢復、心跳租約及自動重連。
- 等待階段移除玩家（撤銷現有憑證），釋出名額。匿名使用者仍可重新申請加入；這不是永久身分封鎖。

## 本機啟動
1. 安裝Node.js 22.18以上（建議24版）。
2. 在專案根目錄執行 `npm ci`。
3. 複製 `.dev.vars.example` 成 `.dev.vars`，設定至少24字元的隨機ADMIN_SECRET。
4. `npm run dev`（自動建置並套用本機D1 migration），開啟 http://localhost:8787/?admin 。
5. 登入後新增題庫，填題並儲存草稿，確認各回合至少一題後發布。
6. 前往 http://localhost:8787/?host ，選用已發布題庫並建立房間，再開啟加入連結。
7. 主持人按開始，玩家選答案；倒數歸零後主持人公布答案，再切下一題或回合。
8. 用不同瀏覽器或無痕視窗測不同玩家。相同瀏覽器的憑證會復用，不會新增玩家。
正式前端輸出至apps/web/build/，不覆蓋根目錄dist/。

現在僅localhost/127.0.0.1/::1可免人機驗證作本機測試。
localhost QR Code不能供另一支手機直接使用。跨裝置測試需另配置HTTPS測試部署與Turnstile。
舊版建立的本機房間沒有新目錄登記，請建立新房間；不會自動將舊房間公開。

## 測試
- `npm run check`：前後端型別檢查。
- `npm test`：7項純邏輯／輸入測試，加上隔離的遊戲、D1／後台Miniflare整合測試。
- `npm run test:admin`：後台API、登入、D1、發布快照及封存測試；不使用正式資料庫。
- `npm run db:migrate:local`：單獨套用本機資料表 migration。
- `npm run build`：前端建置。
- `npm run test:lobby`：對已啟動的localhost:8787測房間與名單。
- `npm run test:browser`：需先執行 `npx playwright install chromium`，再對已啟動的本機服務測試。
- `npm run test:admin:browser`：先安裝Chromium；自動建置並用隔離的本機D1／DO測後台表單、發布、多分頁衝突及XSS字串，不動現有題庫。
HTTP／瀏覽器測試使用測試用管理密碼local-test-only-very-long-secret；勿在公開環境使用。
整合測試中的unsafeInspectDurableObjects只在隔離測試執行，正式Worker不開此入口。

## 本輪安全修正
| 問題 | 防護 |
|---|---|
| 匿名加入占位 | 同IP加入限流、人機驗證、未完成連線名額60秒回收、主持人移除 |
| WebSocket訊息／重連濫用 | 每身分訊息90次／分鐘、同步6次／10秒、重連6次／分鐘；限流後關閉連線 |
| 全場廣播放大 | 玩家提交只回本人ACK；presence合併250毫秒廣播，SQL與在線名單每次廣播共用 |
| 任意房間碼配置物件 | 單一RoomDirectory先查已建立名單，不存在的房間不建立GameRoom |
| 憑證無期限 | 房間24小時到期，關閉房間使全部憑證失效；移除玩家撤銷其憑證 |
| 請求過大 | HTTP串流以位元組限制，超限413；WebSocket訊息2048位元組上限 |
| 瀏覽器防護 | CSP、禁止iframe、nosniff、no-referrer；敏感API no-store；QR不含憑證 |
| 後台登入 | 登入同IP5次／分鐘、後台120次／分鐘；密碼不存Web Storage，Cookie僅HttpOnly |
| 後台修改／CSRF | 所有寫入都查Origin與管理工作階段；SQL使用參數綁定、版本條件更新 |

每IP建立房間5次／分鐘（包含錯誤密碼）、加入30次／分鐘、握手90次／分鐘。
這些是初始保守值；電信商NAT／共用網路可能把多人歸到同IP，必須現場驗證並調整。IP限流不能獨立防止分散式攻擊或真人多帳號。
WebSocket每25秒心跳，租約90秒；失效連線會在alarm回收。手機進入背景可能停心跳，回到頁面需重新整理恢復身分。
未完成連線的玩家不列入已加入名單；確認連線後即保存其身分，斷線不抹除成績。

## 題庫後台操作與資料邊界
- 後台入口 `/?admin`；主持人入口 `/?host`。尚未部署，所以目前沒有公開可用網址。
- 一份題庫最多60題、每題2～4個選項，秒數3～120、配分0～10000；最多100份使用中的題庫。
- 草稿更新不覆蓋發布內容；「發布目前已儲存的草稿」須先儲存未完成變更。建立房間時須確認選定發布版本，若已再發布會回409而非默默換題。
- 刪除題目作用於草稿，按儲存才生效；封存題庫保留資料但不能再選用或編輯，沒有永久刪除按鈕。
- 新發布僅保留最新可選版本，非完整歷史版本系統；已建立房間各自保有原快照。
- 所有管理員共用ADMIN_SECRET，尚無個別帳號、角色分權或操作者稽核紀錄。請勿讓參加者取得管理密碼。
- 正式題目與答案透過後台寫入D1，不必放入公開GitHub程式碼。草稿與答案API必須登入；玩家頁只在公布後收到該題正解。
- 本機D1資料保存在被Git忽略的.wrangler/state，不等於已上傳至正式Cloudflare。
