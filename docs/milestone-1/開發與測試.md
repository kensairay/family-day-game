## 本機啟動
1. 安裝Node.js 22.18以上（建議24版）。
2. 在專案根目錄執行 `npm ci`。
3. 複製 `.dev.vars.example` 成 `.dev.vars`，設定至少24字元的隨機ADMIN_SECRET。
4. `npm run dev`（自動建置並套用本機D1 migration），開啟 http://localhost:8787/?admin 。
5. 登入後新增題庫，填題並儲存草稿，確認各回合至少一題後發布。
6. 前往 http://localhost:8787/?host ，選用已發布題庫並建立房間，再開啟加入連結。
7. 主持人按開始，玩家選答案；倒數歸零後主持人公布答案，再切下一題或回合。
8. 用不同瀏覽器或無痕視窗測不同玩家。相同瀏覽器的憑證會復用，不會新增玩家。
9. 遊戲結算後開啟 http://localhost:8787/?results ，查閱歸檔與下載CSV。房間關閉後仍可查詢。
正式前端輸出至apps/web/build/，不覆蓋根目錄dist/。

現在僅localhost/127.0.0.1/::1可免人機驗證作本機測試。
localhost QR Code不能供另一支手機直接使用。跨裝置測試需另配置HTTPS測試部署與Turnstile。
舊版建立的本機房間沒有新目錄登記，請建立新房間；不會自動將舊房間公開。

## 本輪安全修正
| 問題 | 防護 |
|---|---|
| 匿名加入占位 | 同IP加入限流、人機驗證、未完成連線名額60秒回收、主持人移除 |
| WebSocket訊息／重連濫用 | 每身分訊息90次／分鐘、同步6次／10秒、重連6次／分鐘；限流後關閉連線 |
| 全場廣播放大 | 玩家提交只回本人ACK；presence合併250毫秒廣播，SQL與在線名單每次廣播共用 |
| 任意房間碼配置物件 | 單一RoomDirectory先查已建立名單，不存在的房間不建立GameRoom |
| 憑證無期限 | 房間24小時到期，關閉房間使全部憑證失效；移除玩家撤銷其憑證 |
| 請求過大 | HTTP串流以位元組限制，超限413；WebSocket訊息2048位元組上限 |
| 瀏覽器防護 | CSP、禁止iframe、nosniff、no-referrer；敏感API no-store；QR不含憑證 |
| 後台登入 | 登入同IP5次／分鐘、後台120次／分鐘；密碼不存Web Storage，Cookie僅HttpOnly |
| 後台登出後仍顯示答案 | 跨分頁登出通知、到期與401清除DOM／預覽、舊請求回應攔截（含CSV） |
| 後台探查未知房間 | known_rooms永久登記已建立代碼；查詢／重試先查登記，不配置未知GameRoom；到期仍可重試 |
| 後台修改／CSRF | 所有寫入都查Origin與管理工作階段；SQL使用參數綁定、版本條件更新 |
| 部分歸檔／重複提交 | D1逐批交易、(game_id,player_id)唯一鍵、完整人數閘門；未ready不開放排行／匯出 |
| 成績匯出 | 管理登入、no-store、CSV引號與BOM、文字欄位公式前綴防護 |

每IP建立房間5次／分鐘（包含錯誤密碼）、加入30次／分鐘、握手90次／分鐘。
這些是初始保守值；電信商NAT／共用網路可能把多人歸到同IP，必須現場驗證並調整。IP限流不能獨立防止分散式攻擊或真人多帳號。
WebSocket每25秒心跳，租約90秒；失效連線會在alarm回收。手機進入背景可能停心跳，回到頁面需重新整理恢復身分。
未完成連線的玩家不列入已加入名單；確認連線後即保存其身分，斷線不抹除成績。

## 題庫後台操作與資料邊界
- 後台入口 `/?admin`；主持人入口 `/?host`。測試站為 https://family-day-game-staging.ompstw.workers.dev ，只使用測試內容。
- 一份題庫最多60題、每題2～4個選項，秒數3～120、配分0～10000；最多100份使用中的題庫。
- 草稿更新不覆蓋發布內容；「發布目前已儲存的草稿」須先儲存未完成變更。建立房間時須確認選定發布版本，若已再發布會回409而非默默換題。
- 刪除題目作用於草稿，按儲存才生效；封存題庫保留資料但不能再選用或編輯，沒有永久刪除按鈕。
- 新發布僅保留最新可選版本，非完整歷史版本系統；已建立房間各自保有原快照。
- 所有管理員共用ADMIN_SECRET，尚無個別帳號、角色分權或操作者稽核紀錄。請勿讓參加者取得管理密碼。
- 正式題目與答案透過後台寫入D1，不必放入公開GitHub程式碼。草稿與答案API必須登入；玩家頁只在公布後收到該題正解。
- 編輯草稿時按「題庫手機預覽」，可切換手機寬度與題目、試選答案、模擬公布正解；按Escape或「關閉預覽」返回，未儲存內容不變。較窄的裝置會將預覽縮至可用寬度。
- 登出、登入到期或API回401時，未儲存草稿也會清除；請先儲存。409版本衝突會保留目前草稿。
- 本機D1資料保存在被Git忽略的.wrangler/state，不等於已上傳至正式Cloudflare。

## 成績歸檔操作與邊界
- 後台入口 `/?results`，沿用管理員登入。按「查看成績」可看全部名次與三回合分數；「作答紀錄」可看各題選答、正解、送達時間與是否計分；「匯出CSV」下載總成績。
- 關閉房間／24小時到期不會撤銷管理員讀取D1成績的權限；玩家不能透過成績API取得他人成績或題庫正解。
- 每個房間第一次終止時固定歸檔ID、結算版本與計分截止題。正常完成含全部已公布題；「提前結束」依遊戲結算規則計入當題；中途直接關閉／到期只計已公布題，已送出但未公布的作答保留為不計分紀錄。
- 紀錄只含已完成連線確認的玩家；未確認名額及等待階段被移除者不歸檔。未作答者保留0分，離線玩家不會失去成績。
- outbox保存在GameRoom SQLite；只保存任務描述、固定計分界線和續傳游標，成績與作答留在原SQL表，避免將整場數萬筆作答塞入單一大JSON列。
- 每批20人，每次alarm最多5批；透過json_each與參數綁定批次寫入，每次最多20條D1查詢。每位玩家的作答是小型JSON欄位，題庫快照與總成績分表。
- 成功一批才推進游標；寫入完成但回應遺失可安全重放。完整玩家數吻合才將D1紀錄標成ready，未完成僅在清單顯示「寫入中」，不提供部分排行或CSV。
- 失敗以30秒、60秒、120秒等退避，最多每小時一次，未成功前持續保留任務；外部寫入前先保存安全喚醒時間。若D1缺binding、migration、配額或服務暫時失效，必須修復原因後才能成功，不保證完成時間。
- 結算中的主持人頁可看歸檔狀態；後台輸入房間碼可查未完成任務或立即重試（每房間3次／分鐘）。關閉後的重試不依賴仍有效的主持人token。
- 清單每頁20場；完整排行榜最多350人。CSV為UTF-8 BOM，時間採Asia/Taipei，逗號／引號／換行有轉義，文字開頭的公式符號（含前置空白）加單引號防護。
- CSV包含玩家識別碼與暱稱，仍屬活動資料；請限制分享對象。尚無永久刪除／保存期限設定、個別操作者稽核或自動失敗告警，GameRoom原始紀錄也尚未清除。
- known_rooms保留已建立代碼，公開rooms目錄到期清理不會移除後台重試入口；代碼不再重用。升級前已從舊目錄清除的本機房間不會自動回填，測試請建立新房間；Staging已部署，正式環境尚待建立。
- 350人×60題是本機資料量／歸檔測試，不是350條真實WebSocket或350支手機實機壓力測試。遠端瀏覽器驗收已通過，使用者已開始實機試玩，完整實機驗收與連線壓測仍待執行。
