# Milestone 1 第一階段：正式骨架與房間加入

目前完成：TypeScript/Vite/Workers骨架、受密碼保護的房間建立、QR Code、玩家加入、SQLite持久玩家資料、WebSocket在線名單、自動重連及同身分分頁取代。
尚未完成：出題、計分、題庫後台、D1歸檔、350人壓測、實機彩排。此版本不能直接拿去正式活動。
Prototype dist/index.html保留；正式前端輸出到apps/web/build/。

## 本機啟動（不需Cloudflare帳號）
1. 安裝Node.js 22以上。
2. 在專案根目錄執行 npm ci。
3. 複製 .dev.vars.example 為 .dev.vars，將ADMIN_SECRET改為至少24字元隨機密碼。
4. 執行 npm run dev。
5. 開啟 http://localhost:8787/?host ，輸入管理密碼建立房間。
6. 在其他分頁開啟加入連結，以不同暱稱加入，觀察主持人在線人數。

QR Code若指向localhost，手機不能使用；手機跨裝置測試需改為可到達的電腦區網位址或之後的HTTPS測試網址。
主持人憑證保存在sessionStorage，玩家憑證保存在localStorage；不要共用同一瀏覽器身分當成不同玩家。線上部署需HTTPS。
開新分頁使用相同玩家憑證會取代舊連線；舊分頁停止重連。其他網路中斷會退避重連，最多8次後顯示重整提示。
主持人密碼僅用於建立房間，不放入QR Code或網址。
