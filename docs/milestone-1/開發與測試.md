## 本機啟動
1. 安裝Node.js 22.18以上（建議24版）。
2. 在專案根目錄執行 `npm ci`。
3. 複製 `.dev.vars.example` 成 `.dev.vars`，設定至少24字元的隨機ADMIN_SECRET。
4. `npm run dev`，開啟 http://localhost:8787/?host 。
5. 輸入管理密碼建立房間，再開啟加入連結。
6. 主持人按開始，玩家選答案；倒數歸零後主持人公布答案，再切下一題或回合。
7. 用不同瀏覽器或無痕視窗測不同玩家。相同瀏覽器的憑證會復用，不會新增玩家。
正式前端輸出至apps/web/build/，不覆蓋根目錄dist/。

現在僅localhost/127.0.0.1/::1可免人機驗證作本機測試。
localhost QR Code不能供另一支手機直接使用。跨裝置測試需另配置HTTPS測試部署與Turnstile。
舊版建立的本機房間沒有新目錄登記，請建立新房間；不會自動將舊房間公開。

## 測試
- `npm run check`：前後端型別檢查。
- `npm test`：7項純邏輯／輸入測試，加上隔離的Miniflare整合測試。
- `npm run build`：前端建置。
- `npm run test:lobby`：對已啟動的localhost:8787測房間與名單。
- `npm run test:browser`：需先執行 `npx playwright install chromium`，再對已啟動的本機服務測試。
HTTP／瀏覽器測試使用測試用管理密碼local-test-only-very-long-secret；勿在公開環境使用。
整合測試中的unsafeInspectDurableObjects只在隔離測試執行，正式Worker不開此入口。

## 本輪安全修正
| 問題 | 防護 |
|---|---|
| 匿名加入占位 | 同IP加入限流、人機驗證、未完成連線名額60秒回收、主持人移除 |
| WebSocket訊息／重連濫用 | 每身分訊息90次／分鐘、同步6次／10秒、重連6次／分鐘；限流後關閉連線 |
| 全場廣播放大 | 玩家提交只回本人ACK；presence合併250毫秒廣播，SQL與在線名單每次廣播共用 |
| 任意房間碼配置物件 | 單一RoomDirectory先查已建立名單，不存在的房間不建立GameRoom |
| 憑證無期限 | 房間24小時到期，關閉房間使全部憑證失效；移除玩家撤銷其憑證 |
| 請求過大 | HTTP串流以位元組限制，超限413；WebSocket訊息2048位元組上限 |
| 瀏覽器防護 | CSP、禁止iframe、nosniff、no-referrer；敏感API no-store；QR不含憑證 |

每IP建立房間5次／分鐘（包含錯誤密碼）、加入30次／分鐘、握手90次／分鐘。
這些是初始保守值；電信商NAT／共用網路可能把多人歸到同IP，必須現場驗證並調整。IP限流不能獨立防止分散式攻擊或真人多帳號。
WebSocket每25秒心跳，租約90秒；失效連線會在alarm回收。手機進入背景可能停心跳，回到頁面需重新整理恢复身分。
未完成連線的玩家不列入已加入名單；確認連線後即保存其身分，断线不抹除成績。

## 公開部署的必要設定（尚未操作）
- 新增RoomDirectory SQLite Durable Object binding與v2 migration。
- 用Cloudflare secret設定ADMIN_SECRET與TURNSTILE_SECRET，勿提交.dev.vars。
