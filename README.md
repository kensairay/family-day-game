# 家庭日｜全員出動

公司家庭日手機網頁小遊戲，預計約 250 人、一人一機參加，三回合約 20 分鐘。

## 目前狀態

目前是純前端、本機 prototype，不是多人同步系統。主持人示範按鈕與玩家畫面放在同一頁，正式版將分離。

- 輸入暱稱加入，空白使用「小隊員」；同一瀏覽器內重複暱稱加四位亂數編號。
- 等待主持人開始，三回合各三題（目前為示範題庫）。
- 每題只能選一次；顯示「已收到（本機示範）」，不提前公布答案。
- 主持人手動公布答案、停止收答案並計分；答對固定 260 分，答錯或未作答 0 分，沒有速度加成或自動倒數。
- 主持人手動進入下一題／下一回合，三回合分數累積。
- 個人排行榜顯示此瀏覽器已完成玩家的紀錄，同分並列，不依作答時間排序。
- 主持人可登記本玩家上台決勝後的名次，原答題積分保留。
- 使用 localStorage 保存本機身份、進度與結果；重新整理可恢復。無法使用儲存時會提示。
- 可讓同一玩家重新遊玩，或新增示範玩家以檢查暱稱衝突及並列排名。

「已收到」目前只代表本機記錄，沒有伺服器確認。不同手機／瀏覽器之間不共享暱稱、答案、排名或主持人進度；同一瀏覽器多分頁同時操作也不在本機示範支援範圍內。重新遊玩會在主持人開始時清除本玩家舊分數與決勝名次，不保留歷次紀錄。

## 本機預覽

直接開啟 `dist/index.html`，或在 repository 根目錄執行：

```sh
python -m http.server 8000 --directory dist
```

開啟 `http://localhost:8000`。建議使用 HTTP 預覽，以便可靠地驗證瀏覽器儲存；`file://` 的儲存行為依瀏覽器而異。

## 預計正式架構

採用 Cloudflare Workers Static Assets + Workers API + Durable Objects + D1。照片任務有需求時才加入 R2。

後續 MVP 必須加入：

1. 活動房間、伺服器玩家身份與跨手機暱稱去重。
2. 獨立主持人控制台與只讀投影畫面。
3. 伺服器控制出題、收題、揭曉與固定分數計算。
4. 答案接收確認、重複提交防護、斷線重連與狀態快照。
5. 三回合個人排行榜、上台決勝結果登記與操作紀錄。
6. 300～350 個模擬連線壓力測試及手機／現場彩排。

詳細規劃見 `docs/正式版平台建議.md`。該文件的隊伍功能是早期建議，目前活動採個人競賽，不納入第一版。Sites 設定保留；目前沒有重新執行發布。

## 瀏覽器流程驗證

安裝 Python Playwright 與 Chromium（僅開發驗證需要，玩家不需要安裝）：

```sh
python -m pip install playwright
python -m playwright install chromium
```

啟動上述本機 HTTP 預覽後，在另一個終端執行 `python tests/test_prototype.py`。涵蓋手動揭曉、答對／答錯／未作答、重複計分防護、重新整理恢復、三回合、暱稱衝突、同分並列、決勝名次及不同畫面寬度。瀏覽器模擬不取代 iPhone／Android 實機彩排。
